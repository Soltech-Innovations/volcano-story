# Tell a Story: The Volcano

A four-scene animated story about a volcano eruption, built with JavaScript graphics. Click through the scenes to watch a calm landscape turn into full volcanic chaos.

## The Scenes

1. **The Calm Before the Storm** – A peaceful volcano landscape with a gradient sunset sky, clouds, a river and grass.
2. **Let Destruction Begin** – A dramatic black screen that foreshadows what's coming.
3. **The Awakening** – The sky darkens, the volcano starts to glow, and smoke rises out of it.
4. **CHAOS REIGNS** – The volcano erupts with lava flows and randomly placed flames.

## How to Run

This program was written in CodeHS's JavaScript graphics environment, so it runs on [codehs.com](https://codehs.com) rather than in a regular browser or Node.js.

Click once to start, then click to move to each new scene. After Scene 4, the story is over. Stop the program to end it (each extra click redraws Scene 4 with new flames).

## Built With

- JavaScript (CodeHS graphics library)
- Loops to draw the sky gradient, smoke, lava flows and flames
- Random numbers so the smoke and flames look different every time
- Mouse clicks to move between scenes
